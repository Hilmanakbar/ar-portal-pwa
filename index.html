⚡ Cara Kerja

3 langkah sederhana untuk berbagi model 3D dengan semua pengguna.

1
📤
Admin Upload Model
Admin membuka Admin Panel, konfigurasi GitHub, lalu upload model 3D (GLB, GLTF, OBJ, STL). File tersimpan langsung ke GitHub via API.
2
🚀
Netlify Auto-Deploy
Setiap perubahan ke GitHub secara otomatis men-trigger Netlify untuk redeploy situs. Proses ini memakan waktu ~30 detik.
3
🌐
Semua Pengguna Lihat
Bagikan URL Netlify ke pengguna. Mereka dapat menjelajahi model 3D interaktif dan melihatnya dalam AR dari smartphone manapun.

🌟 Fitur Unggulan

Teknologi modern untuk pengalaman 3D dan AR terbaik.

📱
AR di Semua Device
WebXR di Android, Quick Look di iOS. Lihat model 3D di dunia nyata tanpa install app.
🗂️
model-viewer
Didukung Google model-viewer — zoom, putar, dan pan seperti Sketchfab. Tanpa Three.js error.
🐙
GitHub Storage
Model dan data tersimpan di GitHub repo Anda. Gratis, versi-terkontrol, dan tersinkronisasi.
🌐
Netlify Deploy
Auto-deploy setiap push ke GitHub. CDN global, HTTPS gratis, dan performa tinggi.
